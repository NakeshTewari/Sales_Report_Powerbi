# Sales Report Dashboard - Power BI

## Overview

The Sales Report Dashboard is an interactive Business Intelligence project developed using Power BI.  
This dashboard helps analyze sales performance, profit trends, customer behavior, and regional insights using dynamic visualizations and KPIs.

The project focuses on transforming raw sales data into meaningful business insights for better decision-making.

---

## Features

- Interactive Power BI Dashboard
- Sales & Profit Analysis
- Region-wise Sales Insights
- Category & Product Performance Tracking
- Customer Analysis
- Dynamic Filters and Slicers
- KPI Cards for Quick Overview
- Monthly and Yearly Trend Analysis

---

## Technologies Used

- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Excel / CSV Dataset

---

## Dashboard Insights

The dashboard provides insights such as:

- Total Sales and Profit
- Top Performing Products
- Best Sales Regions
- Monthly Revenue Trends
- Customer Purchase Patterns
- Category-wise Profit Distribution
- Sales Growth Analysis
